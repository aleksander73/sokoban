# Sokoban

<a href="https://en.wikipedia.org/wiki/Sokoban">Sokoban</a> (倉庫番) is a puzzle video game in which the player pushes boxes around in a warehouse, trying to get them to storage locations.

This game clone has been developed in Unity3d game engine.
